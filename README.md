# NavDesk
Navdesk is a browser-based digital chart table for nautical navigation exercises, especially the German Sportbootfuehrerschein See (SBF See). It provides an interactive chart, transparent virtual navigation tools, drawing tools, and viewport controls without the need for a physical paper chart. SPA application (HTML + Javascript), can run locally without a server.
